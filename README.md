# nassauTickets

Sistema de Controle de Atendimento para um Laboratório de Análises Clínicas, desenvolvido como parte da atividade de consolidação de conhecimentos de desenvolvimento Web, organização de projetos, Git/GitHub, documentação, React e integração entre as partes de uma aplicação.

O sistema contempla o controle de emissão, fila, chamada e atendimento de senhas, seguindo os requisitos e regras de negócio definidos na documentação do projeto.
